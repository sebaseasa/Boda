# Boda Sebas & Caro — simulador 3D

Recorrido 3D del jardín de la boda (20 de febrero de 2027, Quito).

- Ver en línea: https://sebaseasa.github.io/Boda/ (agrega `?fps` para ver el contador de cuadros).
- Desarrollo: `npm install` y luego `npm run dev`.
- Compilar: `npm run build` (sale en `dist/`).

Se publica solo en GitHub Pages cada vez que se sube un cambio a `main`.
